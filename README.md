# 志村さんの人生の履歴書

女性B01「花のアルバム」・色01「パールホワイトとローズ」でつづる、1ページ・3篇の物語。

静的HTML・CSS・JavaScript。index.htmlとcss/・js/・images/をそのまま配信します。インストール・ビルドは不要です。文章はindex.htmlが編集元です。

- 本文は標準18px、拡大20/22px。見出しは24〜28pxを中心に設定。
- 章の目次、文字サイズ、動きを止める設定、画像拡大、A4印刷に対応。
- 既存3ページ版とは別のサイトです。
- ご友人から伺ったお話をもとに、友人の目線でつづっています。
- 人物画像・海津大崎画像は提供素材、押し花と区切りはB01の生成装飾です。

既存のページ名memories.html、message.htmlは、それぞれ本ページの第二篇・第三篇へ案内します。
